# Model Governance Card

Create or update the standardized governance record for every ML predictive,
analytical rule, or hybrid model. The canonical procedure is
`.codex/skills/model-governance-card/SKILL.md`.

The card must remain evidence-bound, versioned, and lifecycle-aware. It must
separate observed facts from verified evidence, pending work, not-applicable
fields, and blockers. It cannot inherit production status from a parent model
or claim readiness while placeholders, leakage, population reconciliation,
monitoring, ownership, or rollback evidence remain unresolved.

Machine-readable YAML is the canonical record. Markdown and optional DOCX/PDF
are derived views and must follow the active artifact route.
