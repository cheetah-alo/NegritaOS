# Plain Language Rewrite

## Purpose

Give NegritaOS agents an on-demand way to restate dense technical content in
plain language without weakening evidence, precision, or governance labels.

## Activation

Use through the canonical wrapper:

`/.codex/skills/plain-language-rewrite/SKILL.md`

Activate when the user says `/bro`, `/wait-what`, `/quick`, `sin jerga`,
`habla humano`, `explica simple`, `answer fast`, or asks to simplify a prior
answer.

## Contract

- Change style only.
- Preserve paths, commands, IDs, numbers, dates, metrics, branch names, and
  status labels exactly.
- Keep uncertainty and blockers explicit.
- Do not remove evidence requirements or quality gates.
- Prefer short sentences, active voice, and one idea per sentence.

## Boundary

This is not a license to hide important complexity. If a detail changes the
decision, keep it and explain it plainly.
