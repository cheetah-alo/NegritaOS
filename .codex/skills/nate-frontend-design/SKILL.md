# Nate Frontend Design Adapter

Use the source guidance in `skills/skill_nate/frontend-design-nate/SKILL.md`
only as an opt-in design layer. Existing NegritaOS frontend, accessibility,
dashboard architecture, responsive layout, and product-domain rules remain
authoritative.

Before implementation, define the audience, domain signal, hierarchy,
typography, palette, responsive behavior, interaction states, and visual
invariants. Keep the application usable and connected across pages. Do not
replace real data states with decorative content, introduce inaccessible
contrast, or make a visual rule that conflicts with the project's established
design system.
