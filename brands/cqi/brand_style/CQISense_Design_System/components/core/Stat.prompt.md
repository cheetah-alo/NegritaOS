One metric, stated plainly — the workhorse for calm, ADHD-friendly layouts.

```jsx
<Stat label="Scored accounts" value="144,966" size="lg" />
<Stat label="C · Recall 24h" value="70.5" unit="%" delta="+1.6pt" direction="up" size="lg" />
<Stat label="Median latency" value="14" unit="ms" delta="-9ms" direction="down" goodWhen="down" />
```

`goodWhen` controls delta color. `size`: sm | md | lg | xl (lg/xl for slides).
