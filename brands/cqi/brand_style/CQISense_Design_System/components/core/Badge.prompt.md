Status / label chip. Tones map to the domain model (`repair`, `risk`, `heat`).

```jsx
<Badge tone="repair" dot>Repair</Badge>
<Badge tone="risk" dot>Risk</Badge>
<Badge tone="heat" solid>Priority</Badge>
<Badge tone="neutral" mono>R1</Badge>
```

`solid` for filled, `dot` for a status dot, `mono` for codes/IDs/point values.
