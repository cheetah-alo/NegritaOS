Action control — use for primary/secondary actions; one primary per view.

```jsx
<Button variant="primary" size="md">Promote rule</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost" size="sm">Skip</Button>
```

Variants: `primary` (cobalt fill), `secondary` (outline), `ghost` (text-only), `danger` (pink-red). Sizes: `sm | md | lg`. Pass `iconLeft` / `iconRight` for icons, `full` to stretch.
