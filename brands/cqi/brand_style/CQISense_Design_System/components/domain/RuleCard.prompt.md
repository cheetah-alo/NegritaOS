The one-row contract for an Attr Strict rule — points, mechanism, archetype, support.

```jsx
<RuleCard
  code="R1" title="Callback Promise Debt"
  family="repair" tsr="+8" csr="+10"
  mechanism="PROMISE_DEBT_TO_FRICTION" archetype="C"
  strictCalls="87,626" strictShare="62.5%" status="Proposal" />
```

`family`: repair | risk | priority. Omit `tsr`/`csr` for a priority-route rule (renders "0 standalone").
