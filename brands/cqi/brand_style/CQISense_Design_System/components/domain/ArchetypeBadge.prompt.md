The journey-state archetype — always the final, prioritized label.

```jsx
<ArchetypeBadge code="C" />            {/* token + name */}
```

Codes: A · Resolved Low Pressure, B · Operational Loop, C · Repair Failure/Recall Risk, D · Exit Risk Proximity, D2 · Broken Promise + Exit, E · Silent Failure/Gap, F · Uncertain Review. Import `ARCHETYPES` for the name/color map.
