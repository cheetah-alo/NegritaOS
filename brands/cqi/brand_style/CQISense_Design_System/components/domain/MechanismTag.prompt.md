The mechanism explains *why* a journey is in its state (a journey can carry several).

```jsx
<MechanismTag id="PROMISE_DEBT_TO_FRICTION" />
<MechanismTag id="COMPETITIVE_EXIT_PRESSURE" />
<MechanismTag label="Custom mechanism" family="mixed" />
```

Dot color encodes family: repair (teal), risk (pink), mixed (deep pink), relief (green). Import `MECHANISMS` for the id→label map.
